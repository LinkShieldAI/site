Privacy Policy

LinkShieldAI only collects information needed to provide security checks, operate the service, prevent abuse, and improve reliability.

  • Discord usage may involve reading messages that contain links, plus server IDs, user IDs, channel IDs, and moderation/action logs when needed for functionality.
  • API and developer tools may process submitted URLs, API keys, account identifiers, usage statistics, billing status, request logs, and technical diagnostics.
  • We do not sell personal information. Limited data may be shared with service providers, infrastructure, billing, abuse-prevention, or legal/compliance parties when required to run the service.
  • Data is retained only as long as needed for security, operations, abuse prevention, legal obligations, or basic service functionality.
  • No internet service is perfectly secure, but we use reasonable safeguards to protect operational and account data.
