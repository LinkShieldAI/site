Trust is part of the API
Clear controls and clear limits.
Security verdicts reduce risk; no anti-phishing system guarantees perfect detection. LinkShieldAI exposes stable outcomes, operational controls, and a false-positive path.

      

        
AuthenticationVersioned endpoints require API keys in the Bearer authorization header. Legacy query-key routes remain temporarily available for compatibility.

        
RetentionRequest metadata retention follows the account plan. Submitted URLs may also support threat intelligence, abuse prevention, and service operation as described in the privacy policy.

        
ScreenshotsDetailed scans may capture and temporarily serve a page screenshot. Use standard mode when the workflow does not require visual context.

        
Service providersInfrastructure, logging, payment, security, and support providers may process limited operational data needed to run the service.

        
IncidentsOperational history is published on the status page when measured data exists. Security reports go to support@linkshieldai.com.

        
VulnerabilitiesSend a reproducible report and impact summary to support@linkshieldai.com. Please avoid accessing data that is not yours.
