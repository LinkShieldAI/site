Scanning API

Check any URL with a single request.

Send a URL to POST /v1/scan and get back a verdict of SAFE, MALICIOUS or UNKNOWN, with reason codes you can log or act on.

Get a free API key Read the docs
standard
Fast reputation and threat feed check.
detailed
Adds redirect, page preview, brand and screenshot signals when available.
deep
Adds page fingerprinting when earlier signals are inconclusive. Send "ai": true to add model analysis.

Raw signals

Add include_signals to see what each source returned and apply your own rules.

NSFW check

Find out if a URL is flagged as NSFW.

Chimera

Combines reputation data, fingerprint matching and AI detection into one result.

Usage headers

Every response shows your remaining limits. Throttled calls include Retry-After.

Request

curl -X POST https://api.linkshieldai.com/v1/scan \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","mode":"standard"}'

Response

{
  "request_id": "7f4d...",
  "mode": "standard",
  "verdict": "SAFE",
  "confidence": null,
  "risk_score": null,
  "threat_categories": [],
  "reason_codes": ["KNOWN_SAFE_MATCH"],
  "brand_target": null,
  "screenshot_url": null,
  "freshness": "live"
}

UNKNOWN means no decisive signal was found. Treat it as unverified, not as safe.
